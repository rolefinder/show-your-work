# Project history

**These documents are not maintained.** They record how recruit-me was built —
what was extracted from a private site, what the scaffold looked like partway
through, what the packaging plan was before there was a package. They are kept
because the reasoning is sometimes still useful, and because deleting the
record of a decision is a bad habit.

Read them as dated snapshots, not as instructions. Several name file paths,
repositories, and machine directories that no longer exist. Where they conflict
with [`ARCHITECTURE.md`](../../ARCHITECTURE.md), the ADRs, or the code, the
code wins.
